# Agent guidance

## Project skills

Project-owned skills live in `.agents/skills/`. When a request matches a skill's description, read its complete `SKILL.md` and directly referenced files before acting.

## Agent skills

### Issue tracker

Issues, specifications, and tickets live in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout: domain language belongs in root `CONTEXT.md`, and durable architecture decisions belong in `docs/adr/`. See `docs/agents/domain.md`.
